Overview

SCOUT stores credentials in ~/.scout/config.toml only — never in environment variables or the repository. On Windows that path is C:\Users\<you>\.scout\config.toml.

Graceful skip: Sources without a configured key return empty results and log status=skipped. They never crash an investigation.

Setup workflow

  1. Initialize config: scout config init
  2. Edit ~/.scout/config.toml and paste your keys
  3. Verify (keys redacted): scout config show
  4. Start server: scout serve → open http://127.0.0.1:8765

Example config.toml

[scout] db_path = "~/.scout/scout.db" host = "127.0.0.1" port = 8765 [sources.hibp] api_key = "your-hibp-key" # https://haveibeenpwned.com/API/Key [sources.virustotal] api_key = "your-vt-key" # https://www.virustotal.com/gui/my-apikey [sources.abuseipdb] api_key = "your-abuseipdb-key" # https://www.abuseipdb.com/account/api [sources.github] token = "ghp_..." # https://github.com/settings/tokens

Step-by-step: authenticated sources

Have I Been Pwned (paid)

  • Register at haveibeenpwned.com
  • Go to API Key and purchase the Pwned 1 monthly tier
  • Copy key → [sources.hibp] api_key
  • Header sent: hibp-api-key

VirusTotal (free)

  • Sign up at virustotal.com
  • Open My API Key from your profile
  • Copy key → [sources.virustotal] api_key
  • Header sent: x-apikey

AbuseIPDB (free)

  • Create account at abuseipdb.com
  • Navigate to Account → API
  • Create and copy key → [sources.abuseipdb] api_key
  • Header sent: Key

GitHub PAT (free)

  • Go to GitHub token settings
  • Generate new token (classic)
  • For public user/repo data, no special scopes are usually required
  • Copy token → [sources.github] token (note: field is token, not api_key)
  • Header sent: Authorization: Bearer …

Recommended starting point

  • Zero cost: Gravatar, crt.sh, DNS resolver work with no keys
  • Free keys first: VirusTotal + AbuseIPDB unlock full threat-mode IP lookups
  • GitHub token: Unlocks footprint username investigations
  • HIBP last: Only paid source; add when you need breach data for emails you own
Security: Keep config.toml private. SCOUT binds to 127.0.0.1 by default — local-only, single-user.
